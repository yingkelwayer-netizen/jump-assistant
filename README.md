## 本版变化

优化大平台反馈窗口和彩色条纹平台顶面中心识别。保存本机有界校准结果，修改系数或恢复默认参数可重置。只有“平台超出画面”和“画面不稳定”在 3 秒后重试，每跳最多 3 次；手动暂停不自动恢复。

发行构建使用本地测试图像，通过 222 项客户端断言和 13 项服务端测试。真机截图未公开，公开构建会跳过依赖截图的视觉和落点测试，仍执行 24 项授权断言。**连续 1 万分无错误尚未验证通过**，不保证每次中心连击或兼容全部皮肤、设备及游戏版本。详见 VALIDATION-1.3.3.md。

## 使用

联网输入真实兑换码激活。每码绑定一台设备，有效期 7×24 小时，不同新码可顺延剩余期限，无自动续费。活动开启时，点击分享并成功打开 Android 分享面板会发起领取；系统通用分享接口不能确认真正发送。每台设备每 7 天可再次领取，具体以服务端状态为准。

阅读权限说明并开启无障碍辅助。部分 Android 13 及以上设备先需在应用信息页“更多”中允许受限设置，菜单由厂商决定。打开微信跳一跳，默认紫色棋子，先单步校准再连续；暂停停止后续动作，收起同时隐藏控制条。部分系统强行停止会关闭无障碍开关。

已激活期限内游戏识别、跳跃无需联网。激活、核验、领取、检查和下载更新使用 HTTPS。启动时检查签名清单，已知有新版时要求完成系统确认安装或退出应用；不会静默安装。正式版本不保存或上传游戏截图，不读取联系人、聊天内容，不含广告和统计 SDK。

## 源码与构建

- app：原生 Java Android 客户端与资源。
- server：Node 授权、领取和签名更新服务，无第三方运行依赖。
- server/web：固定下载页、二维码及发布包脚本。
- tests：视觉、落点、授权回归程序；longrun 是显式诊断构建的本地观察工具。
- brand：应用图标、分享图片及生成脚本。

按 TOOLCHAIN.md 准备本地工具与私有签名环境变量，然后运行：

```powershell
pwsh -NoProfile -File ./build.ps1 -ApiOrigin https://your-domain -PublicKeyPath ./your-signing-public.pem
pwsh -NoProfile -File ./build.ps1 -TestOnly
node --test ./server/test.cjs ./server/promo.test.cjs
```

正式构建默认 DIAGNOSTICS=false；只有显式 `-Diagnostics` 才启用本机环形诊断截图，该产物不得替代正式安装包。公开脚本改用环境变量传递签名配置；不含生产签名密钥、口令、授权数据库、真实兑换码、设备序列号、私人截图或生产运维记录。签名公钥是公开验证材料。

自部署参见 server/DEPLOYMENT.md。公开源码是本版快照，发行二进制使用开发者受控签名。每个新版必须递增 versionCode，并同步下载页、APK 和签名更新清单。
